นโยบายความเป็นส่วนตัว (Privacy Policy) — SABA PROMPT

ปรับปรุงล่าสุด: 28 กรกฎาคม 2026

SABA PROMPT ให้ความสำคัญกับการคุ้มครองข้อมูลส่วนบุคคลของท่าน นโยบายนี้ระบุหลักเกณฑ์การเก็บรวบรวม การใช้งาน และการเปิดเผยข้อมูลเมื่อท่านใช้งานแอปพลิเคชันของเรา

1. ข้อมูลที่เราเก็บรวบรวม

  • ข้อมูลบัญชี Google: เมื่อท่านเข้าสู่ระบบผ่าน Google OAuth เราจะขอเข้าถึงข้อมูลโปรไฟล์ทั่วไป (ชื่อ, อีเมล, รูปโปรไฟล์) เพื่อระบุตัวตนและแสดงผลบนระบบ
  • ไฟล์จาก Google Drive: เมื่อท่านใช้บริการนำเข้าเอกสารจาก Google Drive เราจะทำการเปิดเรียกใช้ Google Drive Picker API เพื่อให้ท่านเลือกไฟล์ และนำข้อความมาประมวลผลคำสั่งพรอพท์บนเบราว์เซอร์ของท่าน โดยทางระบบจะอ่านไฟล์ในโหมดอ่านอย่างเดียว (Read-Only) เท่านั้น
  • ข้อมูลการใช้งาน: เราจัดเก็บค่าการตั้งค่าระดับอารมณ์จิตวิทยา (EQ Sliders) และประวัติการทำรายการแบบชั่วคราวบนที่เก็บข้อมูลเบราว์เซอร์ของท่าน (Local Storage) เพื่ออำนวยความสะดวกในการใช้งาน

2. การใช้งานข้อมูล

เรานำข้อมูลของท่านมาใช้เพื่อ:

  • แสดงผลหน้าบัญชีผู้ใช้งานบนแถบแผงควบคุม
  • สกัดข้อมูลคำสั่งสำหรับเตรียมจัดทำประมวลผลร่างอีเมล AI
  • ส่งประมวลผลหา API ปลายทางของโมเดล AI (เช่น Google Gemini) ตามที่ผู้ใช้คลิกตกลงคำสั่ง

3. ความปลอดภัยของข้อมูลและความเป็นส่วนตัวสูงสุด

แอปพลิเคชัน SABA PROMPT ถูกออกแบบด้วยหลักการไร้ฐานข้อมูลจัดเก็บหลังบ้านของระบบ (Zero-Database Architecture) ข้อมูลคีย์และไฟล์เอกสารต่างๆ จะถูกจำกัดการทำรายการและเรียกใช้งานเฉพาะในอุปกรณ์ของท่านเท่านั้น และไม่มีการส่งต่อไฟล์เอกสารหรือข้อมูลบัญชี Google ของท่านไปยังเซิร์ฟเวอร์หรือบุคคลภายนอกอื่นๆ
